# BakaBoost

Marketing landing plus in-app flows (explore, creator pages, shop, gifts, signup, dashboard). Vanilla HTML / CSS / JS. No build step.

## Run
Open `index.html`, or serve the folder:

```
npx serve .
python -m http.server
```

## What’s included
- Landing page with looping hero video, claim-username field, and snap sections
- Explore, how it works, pricing, safety
- Creator pages (posts, shop, gallery, wishlist, members)
- Gift / boost checkout, signup / login
- Creator dashboard, supporter account, and direct messages
- Mobile layout for nav, cards, profiles, forms, modals, checkout, dashboard, and messaging

Reload resets sample state. Fees and creators are demo data.

Enable GitHub Pages in the repo Settings (Deploy from branch: `main` / root) to host the site.
